### 可量化离线证据

在仓库根目录执行：

```sh
python3 -m unittest discover -s tests -v
```

记录结果：**55 tests passed**（1.084 秒）。覆盖 PCM、合成采集流、替身 VAD/端点、唤醒替身、ASR 替身、LLM 替身、Voice Bridge 客户端及编排器状态流转；不包含真实设备录音、真实模型推理、真实 LLM 请求或真实 Voice Bridge 播放。测试未保存音频或转录。

只读环境盘点可复现为：

```sh
python3 --version
uname -sm
adb devices | awk 'NR>1 && $2=="device" {n++} END {print "adb online devices:", n+0}'
adb shell getprop init.svc.mixer
python3 - <<'PY'
import importlib.util
for name in ('openwakeword', 'sherpa_onnx', 'onnxruntime'):
    print(name, 'available' if importlib.util.find_spec(name) else 'not installed')
PY
curl -fsS --max-time 2 http://127.0.0.1:8765/health
curl -fsS --max-time 2 http://127.0.0.1:8080/health
```

ADB 计数命令只打印在线设备数量，不打印序列号。执行健康检查前应遵循共享服务清单，确认服务状态；不要把 Bridge 健康检查误当作播放验收。
