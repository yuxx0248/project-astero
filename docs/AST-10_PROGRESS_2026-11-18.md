# AST-10 进度存档 — 2026-11-18

## 已实现

- 仓库内的本机常驻服务、loopback HTTP API、健康检查与实际监听状态、自动重新监听、用户级 systemd 模板。
- SQLite 会话、任务、上下文、知识和显式记忆接口；音频原始数据、派生音频与诊断信息保存在仓库外。当前调试阶段全量保留，无 TTL。
- 统一 trace、阶段耗时、错误状态与首次观察播放状态的事件。
- 通道 6 主输入、通道 5 辅助 KWS，共享关键词模型，使用重叠窗口限制长监听状态；ASR 使用主通道。
- 缩短 VAD/端点重复静音等待、减少 Codex 对话调用的无用工具启动、保留原模型和推理配置。
- ADB 使用无 PTY 的双向传输；采集正常退出、有效短尾帧保存、读线程排空同步、ASR/LLM 阶段持续原始归档。

## 验证结果

- 开发工作区全量 130 项测试通过；与远端最新 main 集成后的发布提交，在隔离副本中完整运行 135 项测试并全部通过。
- 同题四轮对照的平均“问题播完→答案播完”由 9.93 秒降至 7.44 秒（约 25%）；这是有限样本结果，不能保证每轮达到该延迟。
- 最终固定 TTS 音频经扬声器→Echo 的三轮实测：首次唤醒 3/3，音频归档完整 3/3；回答结束后约 0.8 秒恢复监听。
- 用户参与的三次 Astero 发音，离线回放均可检测；在线只在首轮等待唤醒状态触发，后两次发生于收指令和处理阶段。
- 采集正常退出实测约 0.086 秒；录音文件大小与 manifest 核对一致。

## 尚未完成

- 最终三轮问答中，一次 ASR 将 France 识别为 friends，一次 LLM 调用失败。LLM 单独复测成功，但原失败原因尚未查清；整体可靠性未全部验收通过。
- 默认 TTS 对孤立 Astero 发音不稳定；英文说明也不能保证每次正确。固定合成样本的命中率不能等同于真人准确率。
- 每轮仍需唤醒词；处理/播报期间不支持再次唤醒或打断。
- 尚未实现回答后免唤醒的连续对话窗口。对话窗口是讨论过的建议，并未实现或验收。
- 尚未实现流式 LLM→TTS；长回答仍需要整段生成后播放，速度有波动。
- 远场、不同环境、长期稳定性和更广泛误唤醒样本仍需验证。
